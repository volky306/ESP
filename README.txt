ESP32 S3 Zero – HiveMQ PWA

1. Nahraj všechny soubory do kořene GitHub repozitáře.
2. V GitHubu otevři Settings → Pages.
3. Source nastav na Deploy from a branch.
4. Branch vyber main a složku /(root), potom Save.
5. Počkej přibližně 1–2 minuty.
6. Otevři zveřejněnou HTTPS adresu v Safari.
7. Doplň MQTT heslo a stiskni Připojit.
8. V Safari zvol Sdílet → Přidat na plochu.
